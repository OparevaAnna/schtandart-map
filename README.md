# SCHTANDART — Интерактивная карта объектов с кластеризацией

Веб-приложение на React + TypeScript для отображения объектов остекления компании **SCHTANDART** на интерактивной Яндекс.Карте с кластеризацией меток и фильтрацией в реальном времени.

## ✨ Ключевые возможности

- 🗺️ **Интерактивная Яндекс.Карта (API 2.1)**:
  - Стартовый фокус на европейской части России с плавным зумом.
  - Кастомные фирменные геометки SCHTANDART.
  - Голубые полупрозрачные кластеры, динамически меняющие размер в зависимости от количества объектов.
  - Автоматическое объединение меток и зум при клике на кластер.
- 🔍 **Фильтрация в реальном времени**:
  - По профильным системам (`system`: SCHTANDART 70, 82, Slide, Thermo 75, ALUMIL).
  - По покрытиям и цвету (`coating`: Белый, Дуб Шеффилд, Антрацит, RAL, Анодирование).
  - По типу объекта (`buildingType`: Коттедж, ЖК, Офис, Таунхаус, Отель).
  - По городу/региону и поисковому запросу.
- 📱 **Гамбургер-меню и адаптивный дизайн**:
  - Меню категорий скрыто по умолчанию.
  - Фирменный логотип SCHTANDART на темной подложке.
  - На мобильных устройствах — кнопка запуска фильтров фиксирована снизу по центру экрана.
- 🏷️ **Попап карточки объекта**:
  - Плавная анимация появления снизу (Motion).
  - Фотография объекта, адрес, спецификация, описание.
  - Кнопка прямого звонка (`tel:`), копирование адреса и переход к маршруту в Яндекс.Картах.
- ⚡ **Архитектура и стек**:
  - **React 19 + TypeScript**
  - **@tanstack/react-query** для кэширования и работы с асинхронным слоем данных.
  - **Tailwind CSS v4** для стилизации.
  - **Motion** для плавных переходов и анимаций.
  - Модульная архитектура с разделением на сервисы, хуки, компоненты и утилиты.

## 🚀 Запуск проекта локально

1. Установка зависимостей:
```bash
npm install
```

2. Запуск в режиме разработки:
```bash
npm run dev
```

Приложение откроется на порту `http://localhost:3000`.

3. Сборка для продакшна:
```bash
npm run build
```
